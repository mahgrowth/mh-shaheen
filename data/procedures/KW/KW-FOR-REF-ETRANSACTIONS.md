# مرجع: قانون المعاملات الإلكترونية وحماية البيانات · الكويت

> سجل مرجعي بدون خطوات · [مؤكد] · تحقق 20/10/2026

- القانون 20/2014 يمنع الشركات تطّلع أو تنشر بيانات شخصية مسجلة إلكترونياً بدون موافقة صاحبها أو قرار قضائي، ويلزمها توضح الغرض وتجمع البيانات بحدوده (المادة 32)
- ممنوع تجمع البيانات بطريقة غير مشروعة أو بدون رضا صاحبها، أو تستخدمها لغرض غير اللي جمعتها له (المادة 35)
- لازم تتأكد إن البيانات دقيقة ومحدّثة، وتحميها من الفقد والتلف والإفشاء (المادة 35)
- صاحب البيانات يقدر يطلب محوها أو تعديلها (المادة 36)
- المخالفة عليها عقوبة بالمادة 37، واللي يدير الشركة فعلياً يتعاقب بنفس العقوبات لو إهماله ساهم بالمخالفة مع علمه (المادة 39) · راجع مختص قبل ما تصمم نموذج جمع بيانات أو قائمة عملاء
