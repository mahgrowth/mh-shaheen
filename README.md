# شاهين (MH Shaheen™)

مكتب تنفيذي بالعربي داخل Claude لشركتك الصغيرة بالخليج: CEO يسألك، يرتب خطواتك، ويفعّل الإدارة اللي تحتاجها وقت ما تحتاجها · يعرف إجراءات التأسيس بالكويت والسعودية والإمارات بهالإصدار، وقطر والبحرين وعُمان بتحديث قادم · ومصمم يوقف قبل أي إرسال أو نشر أو دفع لين توافق برسالة مكتوبة، ويسجّل كل خطوة · وأقوى حماية تكون لما تجهّز إعدادات الأمان (تحت)

**مجاني، بس يحتاج اشتراك Claude (Pro أو Max أو Team أو Enterprise)**

## شنو فيه
- **13 وحدة فيها 125 مهارة:** مكتب الـCEO و12 إدارة (التأسيس، المالية، التمويل، القانونية، الاستراتيجية، التسويق، المبيعات، المنتج، خدمة العملاء، العمليات، الموارد البشرية، التقنية) · كلها خاملة عند التركيب ما عدا مكتب الـCEO، وتتفعّل وقت ما شركتك تحتاجها
- **ست مراحل:** فكرة · تأسيس · إطلاق · أول عملاء · تنظيم · توسع
- **قاعدة إجراءات حكومية للكويت والسعودية والإمارات:** كل خطوة برابطها الرسمي وتاريخ آخر تحقق وحالتها (مؤكد · مرجح · للتحقق)، و«حارس الإجراءات» يرجع للمصدر الرسمي لو المعلومة أقدم من 90 يوم
- **بوابة موافقات وسجل تدقيق:** أي إجراء برا يوقف لين توافق عليه برسالة مكتوبة، والدفع والتوقيع وأي شي ما ينلغي يحتاج تأكيد ثاني مكتوب من الكمبيوتر اللي فيه مجلد «شركتي» (مو من الجوال)
- **داشبورد** يفتح على جهازك بدون إنترنت، وما يتصل بأي مكان · بياناته يحدّثها Claude من ملفات «شركتي»
- **أدلة ربط محايدة:** واتساب، إنستغرام، المكالمات، أنظمة المبيعات

## شنو ما يسويه
- ما يدير شركتك بدالك، وما يغني عن المحامي أو المحاسب
- ما يقدّم أي طلب حكومي ولا يدخل أي بوابة حكومية · يعطيك الخطوات والروابط، وإنت تقدّم بنفسك
- ما يرد على عملاءك من نفسه · فيه أدلة ربط لو تبي، وكل رد ببطاقة موافقة

| المسار | لمن | الخطوات |
|---|---|---|
| **أ · Claude Desktop (Cowork)** · الأساسي | أغلب الناس | Customize ← Plugins ← Add ← Add marketplace ← اكتب `mahgrowth/mh-shaheen` ← ثبّت «mh-shaheen» |
| **ب · claude.ai** | اللي ما يبي يركّب برنامج | نفس طريقة أ من إعدادات حسابك، أو ارفع ملف الـplugin (zip) من صفحة الإصدارات |
| **ج · Claude Code (v2.1.275 أو أحدث)** | التقني | `/plugin install mh-shaheen --marketplace mahgrowth/mh-shaheen` · أو بأمرين: `claude plugin marketplace add mahgrowth/mh-shaheen` ثم `claude plugin install mh-shaheen@mh-shaheen` |

**جهّز الأمان قبل أول استخدام:** وضع الأذونات Manual (يدوي)، مو Auto ولا Skip · أدوات الإرسال والنشر بالموصلات «Needs approval»، وأدوات الدفع والحذف «Blocked» بالذات، لأن «Blocked» بس هي اللي تمنع بكل الأوضاع · هذي أقوى حماية عندك فوق بوابة الموافقات

**تأكد إنها النسخة الأصلية:**
- المصدر الرسمي الوحيد: `github.com/mahgrowth/mh-shaheen` · أي نسخة من مكان ثاني، حتى لو بنفس الاسم، ممكن تكون معدّلة وما فيها بوابة الموافقات
- Anthropic ما تراجع الـplugins اللي تنضاف من رابط أو ترتفع كملف، فتأكد من المصدر بنفسك
- لو بترفع ملف zip (المسار ب): نزّله من صفحة Releases بالمستودع الرسمي بس، وطابق بصمته مع `SHA256SUMS.txt` بنفس الصفحة قبل الرفع
  - Mac: `shasum -a 256 mh-shaheen-0.1.0.zip`
  - Windows (PowerShell): `Get-FileHash mh-shaheen-0.1.0.zip -Algorithm SHA256`
- التحديثات: خلّ «Sync automatically» مطفي، وحدّث بنفسك بعد ما تقرا ملاحظات الإصدار

**أول خطوة بعد التركيب:** سوّ مجلد اسمه «شركتي» واختاره، وقل «ابدأ» · الـCEO يبدأ جلسة التعارف
