# فتح ملف منشأة · السعودية

> **[مؤكد]** من صفحة الخدمة الرسمية لوزارة الموارد البشرية · آخر تحقق 18/10/2026

**متى**
- قبل أول موظف، بعد ما يصدر السجل التجاري

**شنو تسوي**
- قدّم الطلب إلكترونياً: نوع المنشأة ونشاطها، بيانات مقدم الطلب والمنشأة والعنوان، وارفق الرخص والوكالة لو فيه
- الرسوم: مجانية، والتنفيذ فوري (المصدر: وزارة الموارد البشرية · 18/10/2026)

**انتبه**
- رقم السجل التجاري ما يتكرر على مستوى المملكة، فملف رئيسي واحد لكل سجل
